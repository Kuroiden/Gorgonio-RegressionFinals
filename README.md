# How's My Laptop's Battery Health? 
Regression finals output. Made using Python, HTML and CSS.

[Laptop Battery Health Prediction Dataset](https://www.kaggle.com/datasets/dharmendrapandit12/laptop-battery-health-dataset) by dharmendrapandit12 on kaggle
## Requirements
- Flask
- Joblib
- Pandas
- Pydantic 
- Scikit-learn
## How to Set-up
1. Run `cmd` and change the directory to the project's root folder
2. Enter `flask run` to start the server
3. Go to `127.0.0.1:5000` to use the app
